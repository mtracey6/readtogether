# ELD AI: Read Together

An employer-facing project case study for a WIDA-informed Grade 3–4 lesson-planning, teaching-library, student-reading, and formative-review prototype designed by Matthew Tracey.

## Status

Pre-pilot local prototype and public portfolio interaction. A private product-owner dry run has occurred, but there has been no educator or student research, classroom use, school partnership, assessment validation, or measured outcome.

## What this repository demonstrates

- EdTech product framing grounded in classroom experience
- WIDA ELD Standards Framework, 2020 Edition-informed planning
- Grade 3–4 lesson planning, Teaching Library, student reader, and formative Reading Check workflow
- Twelve complete demonstration texts across multiple genres
- Fictional, in-memory assignment and student-response behavior
- AI payload allow-listing and student-PII exclusion
- Public-demo rate limits and spend controls
- Multilingual and accessible interaction design
- Proposed research gates and explicit stop conditions

## Structure

- `index.html` - static project case study and browser-side demos
- `og-readtogether.png` - social-sharing image
- `backend/` - optional Bun/Hono lesson-generation API
- `DEPLOY.md` - deployment and evidence-status guidance

The static page intentionally works without a live AI backend. The embedded interaction is deterministic and the latest product screenshots are labeled as local, fictional-data demonstrations.
